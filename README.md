# Website Minh Long

Website giới thiệu dịch vụ IT và catalogue thiết bị của Minh Long (minhlongtek.com), làm bằng **WordPress** + theme riêng.

Toàn bộ mã nằm trong thư mục [`wordpress/`](wordpress/README.md): cách chạy trên máy, cấu trúc theme, cách chuyển lên hosting cPanel.

Bản cũ làm bằng Next.js + Payload CMS được giữ ở git tag `nextjs-payload`:

```bash
git checkout nextjs-payload
```
